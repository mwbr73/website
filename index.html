BachelorarbeitBachelor's thesis

THM · Fachbereich MNI · 2026THM · Dept. of Mathematics, Natural Sciences and Computer Science · 2026

Konzeption, prototypische Umsetzung und Evaluierung einer leichtgewichtigen Testinfrastruktur für ein Brownfield-Remote-Lab auf Basis von ISO/IEC/IEEE 29119

Design, Prototypical Implementation, and Evaluation of a Lightweight Test Infrastructure for a Brownfield Remote Lab Based on ISO/IEC/IEEE 29119

MICRO hatte keine systematischen Tests, nur implizite Schnittstellenverträge, und Breaking Changes fielen erst spät auf. Ich habe die Norm ISO/IEC/IEEE 29119 bewusst auf das Nötige reduziert: Statt eines Risikoregisters gibt es zwei kritische Testfaktoren, funktionale Korrektheit und Schnittstellenkonformität. Beide werden über blockierende CI-Gates durchgesetzt statt über verpflichtende Reviews. Am Beispiel des UART-Service entstanden Unit- und Integrationstests, eine vollständig aus dem Code generierte API-Spezifikation und ein eigener Check, der undokumentierte oder ungetestete Routen findet.

MICRO had no systematic testing and only implicit interface contracts, so breaking changes surfaced late. I deliberately cut the ISO/IEC/IEEE 29119 standard down to what was needed: instead of a risk register, two critical test factors, functional correctness and interface conformance, are enforced through blocking CI gates rather than mandatory reviews. Using the UART service as the case study, I built unit and integration tests, an API specification generated entirely from the code, and a custom check that flags routes that are undocumented or untested.

Evaluiert habe ich das Ganze mit Mutation Testing, einer zweistufigen Entwicklerumfrage und einem Experteninterview. Ein Ergebnis: In einem hardwaregebundenen System stoßen klassische Unit-Test-Prinzipien messbar an ihre Grenzen.

The evaluation combined mutation testing, a two-round developer survey and an expert interview. One finding: in a hardware-bound system, classical unit-testing principles hit measurable limits.
